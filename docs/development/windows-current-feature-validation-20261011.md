This record adds scoped Windows Editor and official-Bridge device Development/Release Player evidence for selected current URP/HDRP fixtures, plus one pipeline-independent pre-rendered playback probe. The Player samples use the device-output route; they do not validate the rendering-only Standalone Player route. It is not a release approval, a general Windows Player result, or a physical-display optical review.
