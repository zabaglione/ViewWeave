# Quilt Playback

The Bridge package provides an Editor window at **Window > ViewWeave > Quilt Playback**. It plays a validated full-quilt PNG or a completed QuiltRecorder output folder through an already-running Ready Bridge session. Playback is limited to Windows Editor Play mode on Direct3D 11 or Direct3D 12. It does not create or stop a Bridge session, call Native begin/stop, or modify Unity time settings.

The source must match the active Renderer quilt dimensions, grid, view count, and view aspect. Camera lens metadata, when present, must also match the active Renderer. A PNG with a capture sidecar uses that sidecar for geometry. A sidecar-free PNG is accepted only when its filename contains a recognized `_qs<columns>x<rows>a<aspect>` tag; the source geometry is reported as filename-derived. Central 2D captures, incomplete recordings, malformed manifests, non-contiguous frame sequences, and ambiguous geometry are rejected. A single PNG is submitted once and held until Stop; a completed sequence releases playback at end of stream.

Playback owns the Renderer operation guard and the existing Bridge session's output while active. Normal Bridge submissions are blocked before changing the output texture reference or blitting. The playback controller reuses one render texture, submits frames through the existing Ready worker, and skips frames when Editor frame time falls behind. Pause stops submissions and holds the last displayed image. Resume restarts the same validated source cursor. Playback does not alter `Time.captureDeltaTime` or `Time.timeScale`.

Stopping or reaching the end of a sequence stops submissions, waits for a graphics fence, drains/reset the Bridge transfer when the same session remains Ready, then releases the source render texture. Live Auto Render resumes only when the same active session, output generation, Renderer, output component, source/reference cameras, camera clip ranges, profile, quality, and settings remain owned and unchanged. A session fault, disable, quality/configuration change, or application pause invalidates the lease and prevents live-render restoration. A disabled playback owner is polled by the Editor lifecycle pump. If the owner is destroyed, it attempts the Editor GPU ownership handshake synchronously; without proof it retains the texture and renderer guard in the recovery record.

Before Editor Play exit, shutdown, or domain reload, the Editor lifecycle stops submissions and requests a one-pixel readback from the owned playback texture. The source is released only after the request reports completion without error and the final graphics fence passes, plus either a successful Ready transfer reset or a same-generation handoff to the Bridge reaper. Queue drain and cleanup each have a 10-second real-time deadline; expiration without ownership proof retains the resource and renderer guard, and time alone never proves completion. If any proof is missing, a recovery record retains the texture and reports that the Editor must be restarted before retrying. Unity's readback wait has no timeout, so a stalled GPU can stall Editor shutdown. No global GPU wait, fixed delay, forced Native unload, or Native call-order change is used.
