対応範囲を判断する際の要点

  • 色空間: HDRPとURP VFXはLinear必須。セルなしRGB/BGRと旧v3 Metal shaderのmode 0〜4 Gamma／Linear GPU計算は当時の条件で確認しましたが、新shared shaderはWindowsのWARP pixel oracleでは確認済みですが、macOSでは未実行です。Gammaのシーン・機器出力全般とGamma VFXは未検証です。[11] [21]
  • 既定と互換モード: 両pipelineの既定は視点別履歴。明示選択のSharedCameraCompatibilityはTAAを停止し、HDRPではMotion Blur／SSR／SSGI／cloud等も変更します。表のHDRP「設定保持」は既定モードの結果です。
  • 品質と描画数: Full / Half / Quarterを実装。間引いたtileは最近傍viewを複製し、補間しません。一般シーンの光学品質・性能は別途検証が必要です。
  • 検証件数: Windowsの選択PlayMode suiteはD3D11 / D3D12各22/22 PASS、skip 0。各22件はGraphicsCompatibility全件ではありません。HDRP/D3D11 device pause-resume、URP/D3D12 Preview-to-Play、HDRP/D3D12 Preview-to-Playは別々の指定Editor caseで各1/1。HDRP/D3D12の先行fixture失敗はpipeline asset永続化修正前の結果として記録しています。macOS Metal GraphicsCompatibilityは58/58 PASS、skip 0。Windowsの成功をmacOS実行の証拠に、macOSの結果をWindowsへ拡張しません。[14] [19] [4] [19]
  • macOS旧v3履歴（新sourceはMac未実行）: V3校正・セル配列対応版のnative CTest 7/7、合成GPU照合、GoのURP／HDRP機器Editor工程各1件とDevelopment／Release機器Playerを再検証しました。特殊配列の実機は未検証です。Local Preview 6/6、保存・録画2/2、MSAA lifecycle 4/4、描画専用GraphicsCompatibility 58/58は出力変更前の描画fixtureで、描画コードは今回変更していません。[21] [18]
