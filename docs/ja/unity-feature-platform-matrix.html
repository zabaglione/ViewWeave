最終照合: 2026年10月11日（日本時間） · Unity 6000.6.4f1 / URP・HDRP 17.6.0
Windows検証実装: 7a00adf。macOS校正一般化: 4222350。今回のmacOS再検証: abf33b3 ＋ 検証fixture修正（コードhashと結果）。開発版の限定確認です。

WindowsはD3D11／D3D12の指定Editor試験、macOSはURP／HDRPのMetal校正値ベース出力を確認しています。

macOS検証環境: Apple M3 Max、macOS 26.6.2、Bridge 2.6.3、接続機器Looking Glass Go。各セルの確認はこの環境と小規模fixtureの範囲です。他モデルの実機、今回のパネル上の立体感・向き・光学品質、任意シーン・全効果は未検証です。セル配列や非0 modeを返す校正は未対応で、対象機種が旧機種か現行機種かは特定できていません。校正情報の調査

判定の読み方

  • 限定確認記載した環境・試験条件で確認済み
  • 実装あり現行コードにあり、この組み合わせの実行は未検証
  • 設定保持設定保持を確認。効果の画素正確性は未検証
  • 未検証当該条件の対応を確認できる証拠なし
  • 非対応SDKが拒否、または明記した標準機能がない

「限定確認」は記載したOS / API / pipeline / Editor・Player・機器出力とfixtureの範囲に限り、任意のシーン、全効果、全視点の画質を保証しません。「設定保持」は効果を有効に保つ設定を確認した状態で、画素正確性を示しません。「実装あり」は対応予定とは異なり、現行コードにあるがそのセルの実行証拠がない状態です。Windowsで未実行の機能は「実装あり」「未検証」を個別に記載しています。旧経路の成功は現行機器出力の成功として掲載しません。

対応範囲を判断する際の要点

  • 色空間: HDRPとURP VFXはLinear必須。Gamma／LinearのMetal校正GPU計算は確認しましたが、Gammaのシーン・機器出力全般とGamma VFXは未検証です。[11]
  • 既定と互換モード: 両pipelineの既定は視点別履歴。明示選択のSharedCameraCompatibilityはTAAを停止し、HDRPではMotion Blur／SSR／SSGI／cloud等も変更します。表のHDRP「設定保持」は既定モードの結果です。
  • 品質と描画数: Full / Half / Quarterを実装。間引いたtileは最近傍viewを複製し、補間しません。一般シーンの光学品質・性能は別途検証が必要です。
  • 検証件数: Windowsの選択PlayMode suiteはD3D11 / D3D12各22/22 PASS、skip 0。各22件はGraphicsCompatibility全件ではありません。HDRP/D3D11 device pause-resumeとURP/D3D12 Preview-to-Playは別々の指定Editor caseで各1/1。macOSは今回のLocal Preview 6/6、URP/HDRP保存・録画2/2、MSAA lifecycle 4/4 PASS、skip 0。機器Editor全工程はURP／HDRP各1件、Development／Release機器Playerは4/4で自然終了code 0。描画専用のGraphicsCompatibility 58/58はそのfixtureの範囲に限ります。Windowsの成功をmacOS実行の証拠に、macOSの結果をWindowsへ拡張しません。[14] [4]
  • 現行DLL: 現在のBridge shimはSHA-256 4D28B54BC09FFCF0BC2E6F9E645E9A04C6EF59210C79BB784872655DA1837F7A、223,232 bytes。本体・URP・HDRP配布版で一致し、Native CTest 15/15、transport-only 11/11、UPM distribution checkを確認しました。native-provenance.jsonで現行DLL情報を追跡しています。Windows機器出力Editor試験は指定caseのみで、Player、一般運用、光学品質を確認していません。本変更に同梱するsource修正を含む検証結果は、正式リリースの対応保証ではありません。[14] [13]
  • 対象外: 物理演算、AI Navigation、ネットワーク等、Quilt描画・転送と直接関係しないUnity機能はこの表の評価対象に含めません。Vulkan出力、全Looking Glassモデル、hotplug、複数機器、一般性能・全視点光学品質も未確立です。
