現在の対応状況

URP / HDRP × Windows / macOSで、Quiltの複数視点描画とLooking Glass出力に関係するUnity機能を比較します。

最終照合: 2026年10月11日（日本時間） · 基準: Unity 6000.6.4f1 / URP・HDRP 17.6.0
Windows検証コード: 62d0e0cb380bf663e4b33d2ad2095b09e4e872f9 ＋ stdio guard / HDRP renderer修正（7a00adfに収録）。macOS校正一般化: b185d5b ＋ 4222350の差分（検証記録）。元のWindows文書作成時checkout: b185d5b（docs-only）。開発版。正式リリースの対応保証ではありません。

技術者向けガイド · 対応条件の詳細 · 導入・操作

基本描画は両パイプラインに実装されています。WindowsではD3D11 / D3D12の選択Editor試験と限定的な機器Preview遷移を確認し、macOSではMetalの描画専用PlayerとGo接続のURP出力処理を個別条件で確認しています。

Windowsの22件の選択PlayMode suiteはD3D11 / D3D12それぞれ22/22 PASSです。これは全GraphicsCompatibility suite、Player、全機能、全シーン、実機光学品質の保証ではありません。URP TAAの履歴蓄積・視点間分離はWindows未検証です。HDRPはCustom Pass、共有露出、履歴camera lifecycle等を限定確認しましたが、TAA画素・蓄積、複数効果の画素正確性は未検証です。Windowsの機器Preview確認はHDRP/D3D11 pause-resumeとURP/D3D12 Preview-to-Playの指定caseに限ります。macOSの測定は別のApple Silicon / Looking Glass Go環境で行ったものです。現行機器出力はBridge校正値に基づき、GoのURP表示処理・停止を限定確認しました。過去のGo光学確認は一般化前の記録で、現行binaryとnon-Go機器の光学品質は未検証です。[14] [2] [3] [17]

判定の読み方

  • 限定確認記載した環境・試験条件で確認済み
  • 実装あり現行コードにあり、この組み合わせの実行は未検証
  • 過去実績旧revision・旧経路での限定実績
  • 設定保持設定保持を確認。効果の画素正確性は未検証
  • 未検証当該条件の対応を確認できる証拠なし
  • 非対応SDKが拒否、または明記した標準機能がない

「限定確認」は記載したOS / API / pipeline / Editor・Player・機器出力とfixtureの範囲に限り、任意のシーン、全効果、全視点の画質を保証しません。「設定保持」は効果を有効に保つ設定を確認した状態で、画素正確性を示しません。「実装あり」は対応予定とは異なり、現行コードにあるがそのセルの実行証拠がない状態です。Windowsで未実行の機能は「実装あり」「過去実績」「未検証」を個別に維持しています。

対応範囲を判断する際の要点

  • 色空間: HDRPとURP VFXはLinear必須。URP Gammaの過去targeted test成功は、現行Windows／Metal機器出力の一般対応やGamma VFX対応を意味しません。[11]
  • 既定と互換モード: 両pipelineの既定は視点別履歴。明示選択のSharedCameraCompatibilityはTAAを停止し、HDRPではMotion Blur／SSR／SSGI／cloud等も変更します。表のHDRP「設定保持」は既定モードの結果です。
  • 品質と描画数: Full / Half / Quarterを実装。間引いたtileは最近傍viewを複製し、補間しません。静的HDRPの旧48-view画素一致とMetalの履歴pool pruningは、一般シーンの光学品質・性能の証明ではありません。
  • 検証件数: Windowsの選択PlayMode suiteはD3D11 / D3D12各22/22 PASS、skip 0。各22件はGraphicsCompatibility全件ではありません。HDRP/D3D11 device pause-resumeとURP/D3D12 Preview-to-Playは別々の指定Editor caseで各1/1。macOS Metal GraphicsCompatibilityは58/58 PASS、skip 0。Windowsの成功をmacOS実行の証拠に、macOSの結果をWindowsへ拡張しません。[14] [4]
  • 現行DLL: 現在のBridge shimはSHA-256 4D28B54BC09FFCF0BC2E6F9E645E9A04C6EF59210C79BB784872655DA1837F7A、223,232 bytes。本体・URP・HDRP配布版で一致し、Native CTest 15/15、transport-only 11/11、UPM distribution checkを確認しました。native-provenance.jsonには現行DLL情報と、旧F1B / 214,016 bytes artifactの履歴を分けて記録しています。Windows機器出力Editor試験は指定caseのみで、Player、一般運用、光学品質を確認していません。本変更に同梱するsource修正を含む検証結果は、正式リリースの対応保証ではありません。[14] [13]
  • 対象外: 物理演算、AI Navigation、ネットワーク等、Quilt描画・転送と直接関係しないUnity機能はこの表の評価対象に含めません。Vulkan出力、全Looking Glassモデル、hotplug、複数機器、一般性能・全視点光学品質も未確立です。
