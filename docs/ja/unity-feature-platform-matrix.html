現在の対応状況

URP / HDRP × Windows / macOSで、Quiltの複数視点描画とLooking Glass出力に関係するUnity機能を比較します。

最終照合: 2026年10月11日（日本時間） · 基準: Unity 6000.6.4f1 / URP・HDRP 17.6.0
照合したソース: 62d0e0cb380bf663e4b33d2ad2095b09e4e872f9 · 開発版。正式リリースの対応保証ではありません。

技術者向けガイド · 対応条件の詳細 · 導入・操作

基本描画は両パイプラインに実装されています。現行の視点別履歴処理はmacOS Metalで限定検証済み、Windowsでは未検証です。

Windowsの過去のEditor・Player・機器出力実績は、現在のURP TAA経路、HDRP履歴・共有露出経路の検証を証明しません。同梱DLLと同一SHAのURP実機記録はありますが、旧managed経路の限定観測です。macOSの機器出力はApple SiliconとLooking Glass Goの専用経路です。[1] [2] [12]

判定の読み方

  • 限定確認記載した環境・試験条件で確認済み
  • 実装あり現行コードにあり、この組み合わせの実行は未検証
  • 過去実績旧revision・旧経路での限定実績
  • 設定保持設定保持を確認。効果の画素正確性は未検証
  • 未検証当該条件の対応を確認できる証拠なし
  • 非対応SDKが拒否、または明記した標準機能がない

「限定確認」は任意のシーン、全効果、全視点の画質を保証しません。表の「実装あり」は対応予定とは異なり、実装と検証の差を示します。Windowsの基本機能は旧機能表に限定実績がありますが、現行既定経路で再検証されていないため、以下では「実装あり」とします。

対応範囲を判断する際の要点

  • 色空間: HDRPとURP VFXはLinear必須。URP Gammaの過去targeted test成功は、現行Windows／Metal機器出力の一般対応やGamma VFX対応を意味しません。[11]
  • 既定と互換モード: 両pipelineの既定は視点別履歴。明示選択のSharedCameraCompatibilityはTAAを停止し、HDRPではMotion Blur／SSR／SSGI／cloud等も変更します。表のHDRP「設定保持」は既定モードの結果です。
  • 品質と描画数: Full / Half / Quarterを実装。間引いたtileは最近傍viewを複製し、補間しません。静的HDRPの旧48-view画素一致とMetalの履歴pool pruningは、一般シーンの光学品質・性能の証明ではありません。
  • 検証件数: 最新Metal GraphicsCompatibilityは58/58、skip 0。URP MSAAは4/4、URP Edit Mode履歴は1/1、Rig Editorは36/36。58件にVFX全条件、全SRP拡張、全Volume効果が含まれるわけではありません。[4]
  • 現行DLL: 同梱Windows DLLはnative focused試験6件に成功。本体とURP/HDRP DistributionのSHA-256・サイズは、旧URP実機観測のF1B artifactと一致します（214,016 bytes）。2026-10-10のD3D12 Editor公式Bridge出力、Pause/Resume、StopからEdit Previewへの限定観測記録があります。現行履歴経路、HDRPの詳細、機器出力Player、広範な反復試験は未検証です。既存Compatibility／provenanceには実機「未検証」の記載が残るため、この表では同一バイナリの限定観測記録として区別します。[12] [13]
  • 対象外: 物理演算、AI Navigation、ネットワーク等、Quilt描画・転送と直接関係しないUnity機能はこの表の評価対象に含めません。Vulkan出力、全Looking Glassモデル、hotplug、複数機器、一般性能・全視点光学品質も未確立です。
