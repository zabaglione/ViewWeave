更新履歴・検証の詳細

「限定確認」は記載したOS / API / pipeline / Editor・Player・機器出力とfixtureの範囲に限り、任意のscene・全効果・全視点の画質を保証しません。「設定保持」は画素正確性を示しません。「実装あり」は現行コードにあるが、その条件の実行証拠がない状態です。未実施、skip、0件、失敗したgateは成功に数えません。異なる旧経路の成功を現行条件へ移し替えません。

  • Windows: 現行の選択Editor/device条件とサンプルcold-loadの結果は[32]を参照してください。未確認のpipeline/API/mode、Player、光学品質へ拡張しません。
  • macOS: 起動時authoring/discoveryとGo geometryの範囲は[28]です。出力・shaderの別環境測定[24]やQuick Start編集確認[27]を今回のWindows結果へ、またWindows結果をMacへ一般化しません。
  • 履歴: [14]、[19]、[22]、[30]などの詳細は各日付付きreportに残しています。現行行のstatusへ旧条件の成功を移し替えていません。
  • 色・画質: Windows WARPとmacOS Metalの合成shader oracleはそれぞれの記録に限定され、物理panelの光学品質を示しません。全機種、hotplug、複数機器、一般性能も未確認です。
  • 機器情報: scene起動時にBridge APIから一度取得し、失敗時はInspectorの「Refresh Connected Displays」で再試行します。公開APIで接続変更callbackを確認できないため定期pollingは行いません。実機の抜き差しは未検証です。[28]

最終照合日・コード基準・local変更・条件・根拠を含む詳細hash、raw XML、構造化結果は日付付きreportとJSONに保存しています。macOSの実行は別環境で行った独立記録です。
