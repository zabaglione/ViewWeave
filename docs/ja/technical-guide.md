# 技術者向けガイド

開発参加・独自統合のための入口です。導入・操作は[ユーザーガイド](user-guide.md)、現行の利用条件は[対応表](compatibility.md)を参照してください。

| 目的 | 参照先 |
| --- | --- |
| パッケージとデータの流れを知る | [構成](../development/ja/architecture.md)、[platform別の責務](../development/ja/bridge-platform-architecture.md) |
| 出力を組み込む・不具合を調べる | [描画backend](../development/ja/graphics-backends.md)、[出力lifecycle](../development/ja/bridge-output-lifecycle.md)、[plugin更新時の対処（英語）](../development/native-plugin-update-troubleshooting.md) |
| 変更をbuild・試験する | [貢献手順（英語）](../../CONTRIBUTING.md)、[pipeline試験](../../Tests/Pipelines/README.ja.md)、[Player検証（英語）](../../Tests/Pipelines/PLAYER_VALIDATION.md) |
| 描画負荷を調べる | [性能測定](../development/ja/performance.md)、[benchmark手順（英語）](../../Tests/Pipelines/BENCHMARK.md) |
| 対応判定の根拠を確認する | [機能別対応表](unity-feature-platform-matrix.html)、[開発記録](../development/ja/README.md)、[対応表の保守](support-matrix-maintenance.md) |
| 公開・配布を準備する | [公開前の確認（英語）](../development/publication-readiness.md)、[第三者ライセンス表記](THIRD_PARTY_NOTICES.md)、[開発計画](../../ROADMAP.ja.md)、[変更履歴（英語）](../../CHANGELOG.md) |
