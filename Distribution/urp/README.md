# ViewWeave URP Git package

Install this folder from the repository using Unity Package Manager:

    https://github.com/zabaglione/ViewWeave.git?path=/Distribution/urp#main

Use Unity 6000.6.4f1 with the matching Unity URP render pipeline. Start with an ordinary Cube or Box, right-click the Main Camera in the Hierarchy, and choose ViewWeave > Bridge Rig to create a child rig; no sample import or object script is required. On Apple Silicon macOS 26.0 or later, the menu creates Metal output for Looking Glass Go in Desktop Mode; URP has been verified on the device. See the [macOS Metal guide](https://github.com/zabaglione/ViewWeave/blob/main/docs/macos-metal.md). Regular Bridge Worker Sessions support Windows D3D11 and D3D12 Editor Play and Player. D3D12 shares GPU resources with a D3D11 worker on the same adapter and does not read image pixels back to the CPU. For Edit Mode authoring, open the ViewWeaveRig Inspector or Window > ViewWeave > Rig Authoring, assign a Focus Target, then explicitly start Start Local Edit Mode Preview or Start Looking Glass Device Preview. This is a separate Editor preview, not a regular Session. It requires a supported Windows Editor D3D11/D3D12 GPU with GPU ownership proof support; device preview also requires the official Looking Glass Bridge runtime. See the [Quilt authoring guide](https://github.com/zabaglione/ViewWeave/blob/main/docs/quilt-authoring.md). Install and run the Looking Glass Bridge runtime separately. Legacy Direct output is D3D11-only. The optional Windows sample is imported only through Package Manager Samples.
