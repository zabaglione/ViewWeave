# ViewWeave URP Git package

Install this folder from the repository using Unity Package Manager:

    https://github.com/zabaglione/ViewWeave.git?path=/Distribution/urp#main

Use Unity 6000.6.4f1 with the matching Unity URP render pipeline. Start with an ordinary Cube or Box and create GameObject > ViewWeave > Bridge Rig; no sample import or object script is required. Bridge output supports Windows D3D11 Editor Play and Player. Install the Looking Glass Bridge runtime separately. The optional Windows sample is imported only through Package Manager Samples.
