# ViewWeave HDRP Git package

Install this folder from the repository using Unity Package Manager:

    https://github.com/zabaglione/ViewWeave.git?path=/Distribution/hdrp#main

Use Unity 6000.6.4f1 with the matching Unity HDRP render pipeline. The included Windows sample is not imported automatically. In Package Manager, use the package Samples Import action, then install the Looking Glass Bridge runtime and run the generated scene in a Windows D3D11 Player.
